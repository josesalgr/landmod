Volver al editor

Publicar en LANDMOD

Elige una sección y escribe. El aspecto de la web se mantiene automáticamente.

  1. Selecciona el contenido: noticia, artículo científico, congreso, curso o blog.
  2. Crea una entrada o abre una existente. Escribe título y texto en español. Puedes usar negrita, listas, enlaces e imágenes.
  3. Añade la versión inglesa si la tienes. Si falta, la web mostrará el texto original con un aviso.
  4. Completa fecha y enlaces. En una actividad, usa la fecha del encuentro; en una noticia, la fecha de publicación. El enlace de redes es el de un tuit o publicación concreta.
  5. Guarda como borrador: deja desactivado «Mostrar en la web» y pulsa el botón de publicación de Decap. Se guardará el archivo pero no se mostrará en la web. La etiqueta del botón de Decap se refiere a guardar en el repositorio.
  6. Cuando esté listo, activa «Mostrar en la web» y guarda. En local, recarga la web. Con el alojamiento conectado, el cambio se reflejará cuando termine la generación automática.

Artículos científicos

Añade autores, revista, DOI y estado: preprint, aceptado o publicado. El texto es vuestra explicación del hallazgo. Puedes cargar un archivo BibTeX en fichas para revisar.

Imágenes y materiales

El campo de imagen permite subir una fotografía o gráfico. Escribe una descripción de la imagen. Para diapositivas, datos o inscripciones, añade el enlace al recurso.

Esta instalación funciona en el ordenador local. Guarda archivos reales en la carpeta del proyecto; no depende del almacenamiento del navegador. El acceso desde otros ordenadores requiere conectar el repositorio, la autenticación y el alojamiento.

La copia anterior

Si tenías cambios en el editor provisional, puedes abrirlo para exportar una copia. Esos cambios no se transfieren automáticamente al nuevo gestor.
